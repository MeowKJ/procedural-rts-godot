# 单位设计资料

这个文件夹是独立的单位设计资料区，不直接驱动运行时代码。

主 AI 可以把这里的设计转成 `UnitSpec`、`ArtSpec`、`DecalSpec`、`WeaponMountSpec` 等代码结构，但这里本身只保存中文 Markdown 设计稿。

当前文件：

- `unit-spec-design.md`：中文单位设计草案。
- `unit-attributes.md`：中文单位清单和属性草案。
- `unit-table.md`：中文单位表格总览。

已删除视觉图集路线。后续单位美术参考应优先使用 Godot 程序化场景、截图或明确的 ArtSpec 文字规格。

设计原则：

- 单位身份由 `UnitSpec` 统一描述。
- 单位美术由 `ArtSpec` 描述，不能只靠轻型、重型这种粗分类决定外观。
- 联机队伍颜色走贴纸槽 `DecalSlot`，不要把整个单位身体染色。
- 敌我关系颜色只用于选择框、血条、小地图、命令线、警告线。
- 白天、夜晚、雾、腐化等主题色只能改变整体氛围，不能抹掉阵营识别。
