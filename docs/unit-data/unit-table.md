## 快速平衡意图

狗狗整体更耐打、更稳定，适合正面推进和防守。

猫猫整体更快、更脆、更依赖视野和侧翼。

ReturnProtocol 更像战役压力源，单位不追求可玩阵营完整性，优先制造压迫和地图控制。

维修和护盾单位默认低推挤，不能把正在攻击的单位挤走。

所有正在攻击、部署、维修、展开护盾的单位，都应该获得位置锚定权，其他友军优先绕行。
