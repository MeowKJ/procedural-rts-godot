# 单位清单与属性草案

这份文档是 `UnitSpec` 的单位数据草案，不是剧情设定稿。所有数值都是第一版手感目标，后续可以根据实测调整。

写法刻意保持纯 Markdown，不用表格，方便继续补充和拆分。

## 通用字段

每个单位建议包含这些字段：

- 阵营
- 科技等级
- 战场定位
- 标签
- 生命值
- 价格
- 建造时间
- 视野
- 移动
- 碰撞
- 武器挂点
- 能力
- 美术引用
- 队伍贴纸
- 生产建筑
- 可用范围

## 当前缺口

缺少 T2 狗狗远程反步兵单位。可以后续补一个狗狗压制犬或哨戒炮车。

缺少 T2 猫猫纯防空地面单位。当前由猫猫侦察机承担早期防空。

AI 阵营目前偏敌方压力设计，还没有完整经济链。做战役敌人足够，做可玩阵营还需要补生产、采矿、科技升级。

所有价格、血量、射程都需要进沙盒实测。第一轮目标不是平衡完美，而是让单位定位清楚、碰撞手感正确、美术引用能落地。
